# 🎨 Holberton School - Web Front End

## 📋 Description

Collection of front-end web development projects completed as part of the Holberton School curriculum. This repository demonstrates proficiency in HTML5, CSS3, responsive design, and modern web development practices.

## 🎯 Learning Objectives

- Master semantic HTML5 structure and accessibility
- Implement advanced CSS techniques and layouts
- Create responsive designs that work across devices
- Follow W3C standards and best practices
- Understand modern web development workflows

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Advanced styling, animations, and layouts
- **W3C Validator** - Code quality assurance
- **Responsive Design** - Mobile-first approach

## 📁 Projects

### HTML Advanced
Complete implementation of a professional website structure using semantic HTML5:
- Proper document structure
- Accessibility features (ARIA labels, semantic tags)
- SEO optimization
- W3C compliant markup

### CSS Advanced
Advanced CSS techniques and styling:
- Flexbox and Grid layouts
- CSS animations and transitions
- Custom properties (CSS variables)
- Responsive design patterns
- Advanced selectors and pseudo-classes

## 🚀 Usage

Each project folder contains:
- HTML files with semantic structure
- CSS files with organized styles
- README with specific project requirements

### Validation
All HTML and CSS files are validated using W3C standards:
```bash
./w3c_validator.py index.html
./w3c_validator.py css/styles.css
```

## 📚 Key Concepts Covered

- **HTML5 Semantics**: header, nav, main, article, section, aside, footer
- **CSS Layouts**: Flexbox, Grid, positioning
- **Responsive Design**: Media queries, mobile-first approach
- **Accessibility**: WCAG guidelines, ARIA attributes
- **Performance**: Optimized assets, efficient selectors
- **Best Practices**: Clean code, proper naming conventions
